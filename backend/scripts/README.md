# Локальный отчёт прогнозов

Из корня репозитория (Windows 11, активированное Python-окружение проекта):

```powershell
python -m pip install -r backend/requirements.txt
python backend/scripts/generate_prediction_report.py --help
python backend/scripts/generate_prediction_report.py
```

Файл по умолчанию сохраняется в `reports/predictions_ГГГГММДД_ЧЧММСС.xlsx`.
Путь к `.xlsx` задаётся через `--output`; `--tournament` фильтрует по части
названия или ID турнира; `--prediction-type` принимает `Обычный` либо
`С учётом ролей`.

Скрипт использует модели из `app.models`, настройку `DATABASE_URL`, если она
задана, или локальные `POSTGRES_DB`, `POSTGRES_USER` и `POSTGRES_PASSWORD` из
корневого `.env` (подключение к `localhost:5432`). Он открывает транзакцию
PostgreSQL в режиме `READ ONLY`. Скрипт не вызывает Batru.gg, OpenDota или
миграции.

## Как трактуется время прогноза

`Prediction` ссылается на `Draft`, который ссылается на конкретную карту
`MatchGame`; результат карты хранится в `MatchGame.radiant_won`. Историческая
вероятность берётся из строки `predictions`, а фактический победитель
определяется по Radiant/Dire этой карты. Для повторных версий драфта выбирается
самый поздний сохранённый прогноз соответствующего типа. Время получения
прогноза не является причиной исключения.

В модели нет времени окончания карты: `Draft.completed_at` фиксирует готовность
драфта, не окончание игры. Время прогноза не используется как основание для
исключения. Карта без фактического результата не влияет на точность; прогнозы,
полученные после начала или завершения карты, остаются в анализе согласно
заданному правилу.

Для каждой карты и типа прогноза используется последний сохранённый прогноз.
Обычный и role-aware прогнозы отображаются отдельными строками и имеют
раздельные сводные значения и командные винрейты. Винрейт рассчитывается среди
валидных прогнозов, где команда была выбрана фаворитом. Excel хранит временные
значения как UTC без timezone, так как формат ячеек Excel не поддерживает
timezone-aware даты.

На общей и турнирных вкладках также есть отдельные таблицы точности по
диапазонам уверенности и накопительным порогам. Они рассчитываются отдельно
для каждого типа прогноза. Границы диапазонов сравниваются по исходным значениям
вероятностей, а пороги используют строгое условие `>`. Для типа без валидных
прогнозов эти таблицы не создаются; такая пустая пара не является отдельной
выборкой.
